1) ჯერ ეს ორი რამ შეცვალე (აუცილებელია)
-----------------------------------------
ფაილებში არის დროებითი მნიშვნელობები:
   https://cupsays.com      -> შენი რეალური დომენი (მაგ. https://cupsays.com)
   contact@cupsays.com      -> შენი რეალური ელფოსტა
შეცვლა: VS Code -> Ctrl+Shift+H (Replace in Files) -> ჩაანაცვლე ორივე მთელ საქაღალდეში.
(ან მომწერე დომენი და ელფოსტა და მე ჩავანაცვლებ.)
ეს აუცილებელია: canonical, hreflang, sitemap.xml და Contact გვერდი ამაზეა დამოკიდებული.
AdSense-ს რეალური საკონტაქტო ელფოსტა ეხმარება, რომ გვერდი სანდო იყოს.

2) ატვირთვა
-----------
1. ჰოსტინგის File Manager -> public_html (ან www, htdocs)
2. ატვირთე site საქაღალდის შიგთავსი (არა თვითონ საქაღალდე) ისე, რომ index.html პირდაპირ public_html-ში იყოს
3. ჩართე უფასო SSL (HTTPS). საიტი HTTPS-ზე უნდა მუშაობდეს.
4. გახსენი /, /ka/, /ru/ და შეამოწმე, რომ ყველა ბმული მუშაობს.
საიტი უნდა იდგეს დომენის ძირში (არა ქვესაქაღალდეში), რადგან ბმულები /-ით იწყება.

3) Google Search Console (SEO)
------------------------------
1. search.google.com/search-console -> დაამატე შენი დომენი და დაადასტურე მფლობელობა
2. Sitemaps -> ჩაწერე sitemap.xml -> Submit
3. URL Inspection-ით სთხოვე მთავარი გვერდების ინდექსაცია (/, /ka/, /ru/)
ინდექსაცია დღეებს ან კვირებს შეიძლება დასჭირდეს.

4) AdSense
----------
1. google.com/adsense -> დაარეგისტრირე საიტი. AdSense მოგცემს შენს ნომერს (ca-pub-...).
2. assets/config.js-ში ჩაწერე:  adsenseClient:"ca-pub-შენი-ნომერი"
   ამის შემდეგ AdSense-ის კოდი ყველა გვერდზე ავტომატურად ჩაიტვირთება და საიტის დადასტურება შესაძლებელი გახდება.
   (სანამ adsenseClient ცარიელია, საიტზე რეკლამის არავითარი კოდი არ იტვირთება.)
3. ads.txt-ში მოხსენი # და ჩაწერე შენი pub-ნომერი (მხოლოდ ციფრები)
4. AdSense -> Privacy & messaging: ჩართე თანხმობის შეტყობინება (ევროპის/გაერთიანებული სამეფოს მომხმარებლებისთვის)
   ეს Google-ის სერტიფიცირებული უფასო ინსტრუმენტია
5. დამტკიცების შემდეგ Auto ads-ს AdSense-ში ჩართავ. ხელით განთავსებისთვის config.js-ში adSlot-ში ჩაწერე რეკლამის ბლოკის ID.
რეკლამის ბლოკებისთვის ადგილი მხოლოდ მთავარ გვერდზე, სტატიებსა და სტატიების სიაში არის; Privacy, Terms, Contact და About გვერდებზე არა.
(Auto ads, თუ ჩაირთო, AdSense-ის მიხედვით თავად ირჩევს ადგილებს.)

რა შეამოწმებს AdSense და რა უნდა გააკეთო
------------------------------------------
- რეალური, ორიგინალური კონტენტი: ახლა თითო ენაზე 4 სტატიაა (230-380 სიტყვა). დამტკიცების შანსის გასაზრდელად
  მიზანშეწონილია სტატიების გაგრძელება 700-1000 სიტყვამდე და ახალი სტატიების დამატება (მაგ. თითო სიმბოლოს ცალკე გვერდი).
- საიტის სტაბილური მუშაობა, საკუთარი დომენი, Privacy Policy, Contact, About: ყველაფერი უკვე არის.
- საიტი გასართობად არის მონიშნული და ვისიტორს არ ატყუებს: ფოტო არ ანალიზდება, ეს ღიად წერია.
- დამტკიცების გარანტია არ არსებობს, საბოლოო გადაწყვეტილებას Google იღებს.
- არასოდეს დააჭირო საკუთარ რეკლამას და არავის სთხოვო დაწკაპუნება.

5) პასუხების რედაქტირება
-------------------------
assets/answers-ka.js, answers-en.js, answers-ru.js. თითო ხაზზე ერთი ტექსტი, ბრჭყალებში "..." და მძიმით.
ტექსტის შიგნით ბრჭყალი არ ჩაწერო; ჩაწერე «ასე». გახსენი Notepad-ით ან VS Code-ით (არა Word-ით).
topics -> შესაბამისი თემა -> ბოლოში დაამატე ახალი ხაზი. პასუხში ყოველ ჯერზე ამ თემის 2 წინადადება შედის.
sym = სიმბოლოები, fr = ფრაზები ({n} სახელი, {t} მნიშვნელობა), op = შესავლები, en = დასასრულები, readers = მკითხავის სახელები.
